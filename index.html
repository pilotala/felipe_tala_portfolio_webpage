Projects

Developments in analog, digital, and power electronics built with strict tolerances, thermal testing, and precision signal routing.

// Stepper Motor Control Through Photoresistor Response

Smart Blackout

This project was meant to improve my sleep quality by creating a blackout curtain that folds when receiving sunglight in the morning, or after a certain hour, and extends when it gets dark. This embedded system included an ESP32 microcontroller, photoresistor sensor, and stepper motor.

// Power Supply & Regulator with Rectifier & Heatsink

Power Supply & Regulator

This project was meant to linearly regulate the incoming power from the power supply to deliver 14 V at a sustained current up to 750 mA, and turn off once reached 1 A current.

// Python Analog Discovery test automation for finding hardware IV response

Memristor Device Characterization

This project focused on automating the testing and plotting the IV response of the only commercially available memristors back then, which are able to perform "in-memory processing", meaning their output is dependent on real and past time inputs. The automation tool is able to sweep frequency, voltage, and generate individual test plots as well as comprehensive plots.

// FPGA Signal I/O Logic with Verilog

FPGA Processor for Drone ADC

This project focused on developing the digital logic and testbench utilizing hardware-descripitive language to simulate the incoming signal of a drone ADC to process real-time external environment data from its sensors.

// PLL & VCO Encoding, LED Drivers, Troubleshooting

Optical Transmitter-Receiver

This was a 4-person team project for the University of Kansas Capstone. Each year, every senior performs 2 projects to prepare for Capstone, including the Optical Transmitter-Receiver project. It required encoding and decoding and electrical signal through PLL + VCO, and optically transmitting it though the air, at a distance. Our team broke the all-time university distance record, registering 3.4 m between transmitter and receiver, limited by the testing equipment cable length.

// Gardener Robot - in Progress

Gardener Robot - in Progress

This project focuses on developing an autonomous robot that navigates through a 15x20m long garden, cutting and watering grass, while applying pesticide to weed plants, accordingly to the weather. Technologies and skills applied include Raspberry Pi for physical control, weather information access, sensor feedback loops, and CNN training, 3D design, and PCB design.
